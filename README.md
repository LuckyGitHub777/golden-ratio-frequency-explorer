# Golden Ratio — Frequency Explorer

**Explore online:** [Open the public interactive website](https://luckygithub777.github.io/golden-ratio-frequency-explorer/). The hosted experience is the primary visitor entry point; source files and optional local use remain available here.

An interactive mathematical visualization of the golden ratio, golden angle, and related frequency sequences. Optional browser-local sound synthesis lets visitors explore calculated intervals under their own control.

Open [index.html](index.html) in a modern browser. The display uses bundled JavaScript, CSS, a frequency table and vector artwork. No account or external runtime service is required. If your browser restricts local JSON loading, serve the repository with `python -m http.server 8000` and open `http://127.0.0.1:8000/`.

These are **mathematical constructions and illustrative design choices**, not proof of medical, cognitive, spiritual, or other physical efficacy. Keep listening volume comfortable and use sound only if appropriate for you.
